# LayoutGuard

Нативная энергосберегающая macOS-утилита для автоматического исправления русской/английской раскладки и явных опечаток.

## Что уже работает

- перехват ввода через системный `CGEventTap` без опроса и таймеров;
- преобразование `ghbdtn` → `привет` и `руддщ` → `hello`;
- исправление неверной раскладки прямо во время набора, без ожидания пробела;
- преобразование всей текущей фразы, например `lf z levf` → `да я дума`;
- автоматическое переключение системной раскладки после исправления;
- полноценный русский словарь Hunspell с морфологией и более чем 550 тысячами словоформ;
- осторожное ранжирование исправлений с поддержкой перестановок букв и двух ошибок в длинных словах;
- меню в строке меню и окно настроек;
- запрос разрешения Accessibility;
- остановка обработки в защищённых полях и менеджерах паролей;
- отсутствие сети и сохранения набранного текста.

Неверная раскладка исправляется сразу, как только слово распознано с достаточной уверенностью. Если перед ним уже набрана часть предложения в той же неверной раскладке, она преобразуется вместе с ним. Обычные опечатки исправляются после пробела или знака пунктуации, чтобы уменьшить количество ложных срабатываний.

Автокоррекция не меняет первую и последнюю буквы слова и не исправляет слова короче пяти букв. Перед исправлением русское слово проверяется по Hunspell: корректные редкие формы вроде `неограненный` остаются без изменений. Это также защищает от смысловых подмен вроде `нпример` → `пример`; правильный вариант в таком случае — `например`.

## Запуск

1. Установите полный Xcode, если он ещё не установлен.
2. В папке проекта выполните:

   ```sh
   xcodegen generate
   open LayoutGuard.xcodeproj
   ```

3. Выберите схему `LayoutGuard` и нажмите Run.
4. В меню LayoutGuard разрешите доступ к клавиатуре.
5. В `System Settings → Privacy & Security → Accessibility` включите LayoutGuard.
6. После изменения разрешения перезапустите приложение.

Для стабильного сохранения разрешения между сборками используйте одну и ту же подпись: Development Team в Xcode либо локальный сертификат подписи для личной сборки.

## Готовое приложение

Собрать настоящий macOS app bundle и ZIP-дистрибутив можно без полного Xcode:

```sh
./scripts/build-app.sh
```

Результаты появятся в `dist/LayoutGuard.app` и `dist/LayoutGuard.zip`.

Для установки в пользовательскую папку Applications:

```sh
./scripts/install-app.sh
```

Скрипт использует локальную подпись `LayoutGuard Local Signing`, если она установлена в Связке ключей, и ad-hoc подпись в противном случае. Для распространения другим пользователям потребуется сертификат Developer ID и нотарификация Apple.

## Проверка движка без Xcode

```sh
./scripts/test-core.sh
./scripts/test-spelling.sh
swift build
```

Полные XCTest-тесты запускаются схемой `LayoutGuard` после установки Xcode.

## Словари и лицензии

Русская орфография проверяется локально через Hunspell 1.7.3 и словарь `ru-spelling-dictionary` 1.0.8. Библиотека статически включена в приложение, а файлы словаря находятся в `Resources/Dictionaries`; установка Homebrew и доступ к сети не нужны. Тексты лицензий включены в `Resources/Licenses`.

## Ограничения MVP

- поддерживаются стандартные раскладки English ABC/U.S. и Russian;
- обычные опечатки исправляются на границе слова;
- для английских опечаток используется системный словарь macOS;
- некоторые игры, удалённые рабочие столы и приложения с нестандартными редакторами могут не поддерживать замену выделенного текста через Accessibility;
- список исключений пока задаётся в коде.

## Энергопотребление

Приложение событийное: пока пользователь не печатает, движок не выполняет периодическую работу. Во время ввода в памяти хранится только текущая незавершённая фраза длиной не более 512 символов; анализ запускается только при поступлении клавиш.

## Приватность

- приложение не выполняет сетевые запросы;
- набираемый текст не записывается в файлы, логи или аналитику;
- в памяти хранится только текущая незавершённая фраза длиной не более 512 символов; она очищается в конце предложения, при клике и смене приложения;
- обработка приостанавливается для защищённых полей ввода и известных менеджеров паролей;
- исходный код не содержит ключей, токенов или внешних сервисов.

Для работы системного перехвата клавиатуры macOS требует разрешение Accessibility. Его можно отозвать в любой момент в `System Settings → Privacy & Security → Accessibility`.

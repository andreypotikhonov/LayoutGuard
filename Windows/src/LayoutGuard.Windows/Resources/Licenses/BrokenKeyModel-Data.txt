LayoutGuard Windows broken-key model data notice

The model weights and vocabulary filter in Resources/Models are generated by
the reproducible scripts in Windows/ml from these bundled sources:

- Russian LibreOffice Extension Dictionary (modern), MPL-2.0.
- FrequencyWords Russian OpenSubtitles 2016 data, CC BY-SA 4.0.

The complete applicable license texts and upstream attribution are distributed
next to this notice. To the extent that the generated model is an adaptation of
the frequency data, it is distributed under CC BY-SA 4.0.

The model runs locally and contains no captured user typing.

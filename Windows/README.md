# LayoutGuard for Windows

Локальный автокорректор для Windows 10/11: исправляет текст, набранный в неверной раскладке, обычные опечатки, пропущенные пробелы и пропуски из-за неисправных клавиш.

## Скачать

### [Скачать установщик LayoutGuard-Setup.exe](https://github.com/andreypotikhonov/LayoutGuard/releases/latest/download/LayoutGuard-Setup.exe)

Запасной переносной вариант: [открыть последний релиз](https://github.com/andreypotikhonov/LayoutGuard/releases/latest) и скачать `LayoutGuard-Portable-x64.zip`.

Windows может показать предупреждение SmartScreen: у личной сборки пока нет коммерческого сертификата подписи. В таком случае нажмите «Подробнее» → «Выполнить в любом случае». Приложению не нужны права администратора.

## Что умеет

- `ghbdtn` → `привет` и автоматическое переключение на русскую раскладку;
- исправление всей ошибочно набранной фразы, а не только последнего слова;
- `ривет`, `пивет`, `ивет` → `привет` при выбранных неисправных клавишах `п`, `р`, `э`;
- `кзамен` → `экзамен` и `лектрон` → `электрон` при пропущенной `э`;
- восстановление пропущенных букв в начале, середине и конце слова;
- `сейчасскаким` → `сейчас с каким`;
- обычные опечатки и личный словарь слов, которые нельзя изменять;
- защита нормальных редких слов: например, `неограненный` не заменяется на `неограниченный`;
- компактный офлайн-словарь из 3,35 млн русских словоформ и локальная контекстная статистика для предустановленных `п`, `р`, `э`;
- имена и их формы, включая `Андрей`, `Андрея`, `Андрею`, `Андреем` и `Андрее`;
- настройки всех неисправных клавиш; для других выбранных букв используется словарный механизм.

Модель никогда не переписывает уже корректное словарное слово: например, `кран`
не превращается в `экран`. Общая орфографическая коррекция остаётся отдельной
опцией и выключена по умолчанию.

После запуска значок LayoutGuard появляется возле часов. Дважды щёлкните по нему, чтобы открыть настройки. По умолчанию уже выбраны неисправные клавиши `п`, `р`, `э`; набор можно изменить в этом окне.

## Приватность и энергопотребление

Весь анализ выполняется локально. Текст не сохраняется, не отправляется в интернет и не используется для аналитики. В полях паролей и в менеджерах паролей обработка приостанавливается. Приложение реагирует на события клавиатуры, поэтому не опрашивает систему в постоянном цикле и почти не нагружает процессор в простое.

Настройки хранятся только в `%LOCALAPPDATA%\LayoutGuard\settings.json`.

## Разработка

Требуется .NET 8 SDK. Команды выполняются из папки `Windows` основного репозитория.

```powershell
dotnet run --project tests/LayoutGuard.Core.Checks/LayoutGuard.Core.Checks.csproj -c Release
dotnet run --project tests/LayoutGuard.Windows.Checks/LayoutGuard.Windows.Checks.csproj -c Release
dotnet build src/LayoutGuard.Windows/LayoutGuard.Windows.csproj -c Release
```

Финальную работу глобального перехвата ввода и переключения раскладки нужно проверять на Windows; ядро коррекции тестируется независимо от ОС.

Сторонние словари и библиотеки перечислены в [THIRD_PARTY.md](THIRD_PARTY.md).
